# Payment method logos

Place logo images in this folder using exactly these file names (PNG, ideally square with a transparent
background). The admin panel and checkout pick them automatically. If a file is missing, the default icon
is shown. The list comes from `apps/web/lib/paymentProviders.ts`.

## General

| Provider                                   | File name              |
| ------------------------------------------ | ---------------------- |
| Cash on delivery                           | `cash-on-delivery.png` |
| Raast (all Raast methods)                  | `raast.png`            |
| Card payment                               | `card.png`             |
